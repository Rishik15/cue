# Changelog

## 0.1.0 (first release)

Windows 10 and 11. Not code-signed yet.

- Dictation with offline speech models, live caption, vocabulary, filler removal, saved actions.
- Selection palette: clean up, convert, extract and Markdown actions on selected text, with an optional local text model.
- Grab Text: read text from any part of the screen with Windows' built-in recognition.
- Snippets: typed triggers, folders, regex triggers, placeholders, questions, imports from Raycast, Espanso, TextExpander and AutoHotkey.
- Dictionary: a card under the selected word with meanings, examples and synonyms (English pack downloaded on demand).
- Six theme families (Light / Dark, GitHub, One, Catppuccin, Tokyo Night, Dracula), each with light and dark, shared by the settings window and the native windows. Inter throughout.
- Tray-only process at about 4 MB and 0 % CPU when idle; engines run in separate processes that exist only while used.
