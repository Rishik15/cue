# Changelog

## 0.1.1

- A clearer first run: a short intro page, a plainer shortcut hint, an optional AI text model page and shorter page texts. The Download buttons no longer have a hand-drawn arrow.
- Settings hints are written in plainer words.
- Deleting a rule, snippet, folder, downloaded model or all data now asks for a second click on the button itself instead of opening a popup. Removing a saved word takes one click.
- The close button is red on hover in every theme.
- Remove All Cue Data tries again for up to ten seconds if a file is still in use, and the uninstaller removes the install path key it used to leave in the registry.

## 0.1.0

The first release, for Windows 10 and 11. It is not code-signed yet.

- Dictation with offline speech models, a live caption, custom words, filler removal and saved steps.
- A selection palette for cleaning up, converting and extracting text, with an optional local text model.
- Grab Text, which reads text from anywhere on screen.
- Snippets with typed triggers, regular expressions, placeholders and imports from Raycast, Espanso, TextExpander and AutoHotkey.
- A dictionary card for any selected word, using an English pack you download once.
- Six theme families, each with light and dark.
